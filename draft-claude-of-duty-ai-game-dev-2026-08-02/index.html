AI 辅助游戏开发的新边界：从 Claude-of-Duty 看 Three.js 与 AI 编程的结合

最近在浏览 GitHub 时，发现了一个很有意思的项目——Claude-of-Duty，由开发者 Matt Shumer 使用 Claude Code 和 Three.js 构建的类使命召唤（Call of Duty）品质的 FPS 游戏原型。

这个项目本身或许不算复杂，但它代表了一个值得关注的趋势：AI 编程工具正在突破”写代码”的边界，进入”构建完整交互体验”的领域。

从工具到创作者

过去我们用 AI 编程工具写脚本、写 API、写 CRUD 应用。但 Claude-of-Duty 展示了不同的可能性——开发者可以声明一个模糊的目标（”做一个使命召唤品质的游戏”），然后 AI 自主完成从 3D 场景搭建、游戏逻辑编写到交互实现的全部工作。

Three.js 作为 Web 3D 渲染库，本身就有一定的学习曲线。但在 AI 的辅助下，开发者不再需要逐行理解 Three.js 的 API 文档，而是可以通过自然语言描述需求，让 AI 生成完整的 3D 游戏界面。

Goal Coding 的实践案例

这个项目也是 Goal Coding 范式的生动体现。开发者没有一步步指挥 AI”先建一个场景，再加一个角色，然后写射击逻辑”，而是直接声明了终点——“构建一个使命召唤品质的 FPS 游戏”。AI 自主规划执行路径，完成从零到可运行原型的全过程。

正如刘小排所说：“高手比的是，谁能把’什么叫做完’定义清楚。”

对开发者的启示

  1. AI 编程的边界在扩展：从写代码到构建完整游戏，AI 的能力边界正在快速扩展
  2. 声明式开发成为新范式：告诉 AI”做什么”而非”怎么做”，正在成为更高效的开发方式
  3. Three.js 等前端技术栈受益明显：Web 技术栈的即时可视化特性，让 AI 生成的内容可以立刻被验证和体验
