从 Karpathy 的三个新领域到 OpenCLI：LLM 原生工具正在重新定义软件边界

最近读了 Karpathy 在红杉 Ascent 2026 上的炉边谈话，其中有一个观点让我印象很深：

大型语言模型（LLMs）远不止于加速以前已有的东西，它正在催生三个全新的领域。

三个新领域

1. menugen：LLM 能完全吞没的应用

输入一张图像，输出一张图像——这类任务 LLMs 可以原生完成，不需要任何传统代码。这种应用以前根本不该存在，现在却自然地生长出来了。

2. 用 .md 技能代替 .sh 脚本

为什么要为安装软件写复杂的 bash 脚本？如果你能用文字写出安装过程，把这段文字「展示给 LLMs」，它可以智能地针对你的环境进行安装和内联调试。LLM 是高级的英语解释器。

3. LLM 知识库：传统代码不可能做到的事

用传统代码构建一个知识库几乎不可能，因为知识来自「任意来源、任意格式的无结构数据」。但 LLM 天然就是处理这些数据的工具。

OpenCLI：menugen 的具体实现

Karpathy 的三个新领域不是预言，OpenCLI 已经是一个具体案例。

OpenCLI 将任意网站转换为命令行界面，并在已登录的浏览器中供 AI Agent 使用。

它的核心理念：以前需要为每个网站写爬虫或 API 集成，现在可以用自然语言让 AI Agent 操作任何网站。

OpenCLI 支持 100+ 主流网站（B站、知乎、小红书、Twitter、HackerNews 等），AI Agent 可以通过 opencli browser 原语直接操作这些网站的已登录页面——导航、点击、填表、提取数据。

这本质上就是 menugen：把「浏览器操作能力」LLM 化，不需要传统的网页爬虫或 API 开发。

思考

Karpathy 说：「在每一次新范式转变中，显而易见的事情总是停留在加速已有事物的领域，但真正的价值在于：要么以前根本不该存在（menugen），要么以前根本不可行（LLM 知识库）。」

OpenCLI 印证了这一点。

这些新领域有一个共同特点：它们不是对旧事物的加速，而是以前根本不可能存在的东西。
