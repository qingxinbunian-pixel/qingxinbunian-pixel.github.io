云桥交付进行时：从网页版到桌面版，Codex 驱动的三人项目一周实战

本文整理自 2026-09-11 每周回顾：本周四条主线中，云桥项目的开发与交付推进是投入最深的一条。

项目背景

云桥是一个三人课程项目，目标是从网页版推进到桌面 App 完整交付版——需要打包成安装包发给同学，并附带源码清单。本周开发重心明确：前端优化 + Tauri 桌面化。

开发主力：Codex

这一周的大量开发会话都由 Codex 承担，覆盖了完整的交付链路：

  • 网页版后端基本实现
  • 前端优化增强：围绕网页版交互与视觉打磨
  • 桌面交付版：软件完整交付版 app 版，包含安装包、源码
  • 答辩 PPT：课程答辩材料的制作
  • 图片生成：项目视觉素材（如 AI 操作复杂软件的示意图）

终端记录里反复出现的 pnpm dev 和 npm run tauri dev 印证了开发节奏：前端开发服务器与 Tauri 桌面壳并行联调。

AI 工具链的协同

  • Kimi Code：本周 kimi.com 访问 57 次、累计 1929 分钟，是使用时长最高的 AI 工具之一；远程控制实验（KIMI_CODE_EXPERIMENTAL_REMOTE_CONTROL / kimi rc）延续进行
  • Codex A2A 适配器改造：延续「回忆 codex 适配器改造细节」工作，向 laptop 上的 Hermes 同步
  • Khoj：本地自托管 AI 助手持续评估中，计划用于整理课程错题

下周收敛目标

  1. 明确「云桥网页版/交付版」前端优化清单
  2. 完成 pnpm dev + tauri dev 联调闭环
  3. 产出安装包 + 源码清单作为交付物

一点感想

这周最直观的感受是：交付型项目的节奏被 AI 编程 Agent 大幅提速。从「网页能跑」到「桌面版可分发」，中间隔着前端打磨、打包配置、答辩材料一大堆琐碎工作——而这些恰恰是 Codex 这类 Agent 最擅长的执行型任务。人负责定方向和验收，Agent 负责把路径走完，这个分工在课程项目里已经非常顺滑了。
