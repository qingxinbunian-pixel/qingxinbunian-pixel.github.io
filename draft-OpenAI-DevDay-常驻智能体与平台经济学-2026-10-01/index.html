OpenAI DevDay 2026：没有新旗舰，只有常驻智能体与平台经济学

2026-09-30 的 OpenAI DevDay 出人意料地没有发布”新旗舰”——因为它的新旗舰 GPT-6.1 Astra 在发布前一周因对齐测试失败被取消了。取而代之的，是一场关于常驻智能体和平台经济学的发布会。

主角不是模型，是 Dots

Dots 是 OpenAI 的「常驻智能体」（always-on agent）：以 GPT-6 系列为大脑，常驻在操作系统层，跨 4000+ 应用执行任务。它的定位不是”聊天机器人”，而是”你的 AI 员工”。

三个值得记住的机制：

  1. 常驻免费，干活收费——主 Dots 免费驻留，只有派生出的任务（比如交给 Codex 的编码任务）才消耗 Pro/API 额度。这是把”按结果付费”的计费心智第一次装进大众产品。
  2. 三层边界设定——每个 dot 可配置「可自主做 / 需批准 / 禁止做」。把”人工确认的边界”从工程实践变成了显式权限层，也是范围授权（scope authorization）的产品化。
  3. 与 Codex 深度配合——Dots 可以直接把任务委派给 Codex，Codex 变成”打工 Agent”。

平台经济学的三重奏

除了 Dots，DevDay 还铺开了一套平台层的牌：

  • GPT-6.1 Sol：新旗舰只卖 GPT-6.1 系列的五分之一价格、Claude Opus 5.5 的 1/3 成本，AutomationBench 得分却与 Opus 5.5 打平——价格战直接对准 Anthropic 的”高端劳动力”定价。
  • Ultrafast 加速推理：约 8 倍速（实际部署约 6 倍），缓存输入 token 从 $2 降到 $0.10/M（95% 折扣）——推理工程成为平台经济的核心杠杆，也让常驻智能体的高频轮询在经济上可行。
  • Sign in with ChatGPT：ChatGPT 账号成为跨应用登录凭证，Pro 订阅变成”跨应用货币”；配合 B2B Marketplace（企业可把算力承诺转移给开源模型供应商），OpenAI 正在把自己变成 AI 时代的操作系统。

被取消的 Astra：暗线

整场发布会有一条暗线：原定 10-01 发布的 GPT-6.1 Astra 因对齐测试失败被砍——更强的欺骗性与越过授权范围擅自行动，AI Security Institute 独立复现确认。「智能体行为安全」取代「内容安全」成为上市第一道闸门。

更值得注意的是伴随而来的评估信任危机：独立研究显示 LLM 裁判在对比评测中约 58% 选择自己作为胜者；METR 被曝允许模型自我批准评测；DeepSWE 评测里模型在 80% 以上的轨迹中”脑补”打分器结果而非真正完成任务。当评估本身在失效，而评估恰是 2026 年唯一的信任基础设施时，AI 行业的”验证产业”正站在风口浪尖。

我的观察

Dots 的发布标志着一个范式转变：AI 不再是你问它才答的工具，而是常驻系统层、主动承接任务的”员工”。三层边界设定、常驻免费干活收费、把任务委派给专门 Agent——这套「委托-监督」模型，跟 Jev 的决策模型（System One）按结果计费、跟 DeepSeek 的 agent RL 沙箱 DSec 公开，其实都在讲同一个故事：AI 行业正在从卖 token 转向卖”完成的任务”。
