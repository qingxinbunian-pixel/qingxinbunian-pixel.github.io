Gemini 4 Argon 发布：1M token 输出与「单价减半、消耗翻倍」的算账逻辑

10 月 1 日，Google DeepMind 发布了新一代旗舰模型 Gemini 4 Argon——距离上一代旗舰整整七个月，DeepMind 用一场「反常识」发布重返牌桌：行业首创的 100 万 token 输出上限、正好打到对手一半的促销价，以及一份令人皱眉的 token 账单。

基准：19 个可信基准拿下 13 个 SOTA

Argon 的硬实力不容置疑：DeepSWE 77.9%（反超 Claude Opus 5.5 的 74.2% 和 GPT-6 Astra 的 74.1%）、Vals Index 第一（68.9%，$15.68/任务）、AA Intelligence Index 53（追平 Astra）、AutomationBench-AA 第一（77.5%）、Terminal-Bench 4 从 19.0% 跃升至 57.6%。

两个值得注意的细节：

  • 幻觉率显著更低：AA-Omniscience 幻觉率 15%，而 Astra 高达 51%——虽然准确率 50% 仍低于 Astra 的 63%，但「知道自己不知道」在 agent 场景里比「答得快」更值钱。
  • 法律领域翻车：Harvey 法律基准只有 19.6%，被 Meta Muse Spark 1.2 的 25.42% 压过——没有任何模型是全能的。

行业首创：1M token 输出是怎么做到的

Argon 最大的技术卖点是 100 万 token 输出上限，但实现方式并非单次前向生成，而是 API 层的「Long Decode Continuation」——把一次长生成拆成跨调用续写。这等于把「长输出」从推理引擎难题降维成「状态管理 + 续写调度」的工程问题。

对 agent 工作流来说，这直接改变了「思维预算」的边界：一个 agent 可以一次性产出整本书级别的分析，再也不用绞尽脑汁把任务拆成几十轮短对话。

算账逻辑：单价减半，但消耗翻倍

最反直觉的是定价：促销价 $2/$10（每百万 input/output token），正好是 Claude Opus 5.5 的一半；标准价 $4/$20。但 Argon 每个任务平均输出 62K token——是 Astra（27K）的 2.3 倍。折扣价下每任务成本 $1.99 vs Astra 的 $3.26，确实便宜；可一旦促销结束恢复 $4/$20，同样的任务会比 Astra 贵出 30% 以上。

「单价减半、消耗翻倍」——省钱靠的是单价，不是效率。这给模型选型提了个醒：别再看「谁第一」，要看「每任务 token 成本 × 成功率」的复合指标。缓存倒是真便宜：缓存输入 95% 折扣（$0.10），「整库喂给模型重写」类工作流的成本骤降。

内部狗粮化：模型为自家生态收租

DeepMind 披露的 dogfooding 数字同样惊人：释放 300+ TiB 内存（预计总节省 500 TiB–1 PiB）、80 万行 C/C++ 内核代码迁至 Rust（Fuchsia Zircon、re2、libgav1）、libgav1 中 3.2 万行 SIMD 换成安全 Rust 后视频解码提速 2.7 倍。模型在自己的云和软件栈上产生可审计收益——这正是「模型当诱饵、生态收租」逻辑的强化版：算力规模本身就是护城河。

安全叙事的新常态：发布前共审

Argon 首发仅面向 Fairwind 政府用户与可信网络防御者，且对可信防御者「不加网络护栏」——把最强的攻防能力同时交给红队与防御者。配套内部激活监控（arxiv 2601.11516）与间接提示注入鲁棒性第一的成绩（Gray Swan 基准）。「信任者优先」先于模型能力评估，安全从「发布后打补丁」前置为「发布前共审」，这可能成为前沿模型发布的常态。

一点冷思考

  • 公开榜单上 262K vs 1M 的输出口径差，说明「验证产业」的评测标准仍在缺位，benchmaxxing 的质疑不会消失。
  • DeepSWE 77.9% 能否被第三方独立复现，是未来三个月最值得盯的问题之一。
  • 1M 输出成为 2027 年旗舰标配的概率，我认为在 85% 左右——长时程 agent 的思维预算，已经正式商品化。
