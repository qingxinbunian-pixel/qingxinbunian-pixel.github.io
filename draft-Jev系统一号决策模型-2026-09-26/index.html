不生成文本的 AI：Jev 与「系统一号」决策模型

大模型已经能聊天四年了，自动化在哪里？

这是前 OpenAI 后训练核心成员、InstructGPT 论文联创 Diogo Almeida 的质问。2026 年 9 月，他带着答案回归：Jev——一款不生成任何文本的 AI 决策模型。发布一周，Discord 破 10 万人，社区出现至少 6 个克隆，Latent.Space 为其制作了 141 分钟深度专访，称这是「开发者生态的范式事件」。

它到底做了什么

传统 LLM 是「生成字符串的机器」：输入 prompt，逐 token 自回归吐出文本。Jev 完全不同——

  • 输入：程序状态（state）+ 结构化问题（questions，类型为 Choice / Score / Boolean）
  • 输出：类型化概率分布，如 Payments 91% / Account 6% / Other 3%，不生成任何文本

它消费的不是人类读者，而是代码。名字致敬 Kahneman 的《思考，快与慢》，定位是 machine-native 的 System One 模型；公司名 TypeSafe 致敬 Jevons 悖论——效率提升反而扩大需求，目标是站在「智能/美元」前沿。

硬指标相当惊人：端到端延迟 70–500ms，输入 $0.042/百万 token，输出免费；workflow eval 实测比同级 LLM 快 193.6 倍、便宜 444.6 倍；MMLU-Pro 84.6%。

为什么「不生成文本」这么重要

行业一直困惑：LLM 对话早已超人类，为什么自动化始终没有兑现？Diogo 的答案是——token 级生成慢、贵、会幻觉、无法组合，软件没法把它当成可靠依赖。

Jev 的解法是把模型从「生成字符串」重新定义为「输出带校准概率的类型化决策」。所谓「零幻觉」不是知识上永不犯错，而是类型安全在数学上不可能错：输出 schema 预先定义，结构保证合法；配合每个答案的校准概率，软件可以设阈值自行决定行动或升级人工。

训练范式之争：RLHF / RLVR / RLCD

Diogo 亲历 RLHF 三条支流，认为它们全是「错误的北极星」：

维度 RLHF RLVR RLCD (Jev)
优化目标 人类偏好 程序可验证奖励 校准的决策概率
输出 字符串/对话 可验证字符串 类型化概率决策
采样 逐 token 自回归 逐 token + 迭代验证 并行一次读出
典型问题 幻觉、谄媚、依赖人工 锯齿智能、难嵌入软件 覆盖 System One 任务

RLHF 优化人类偏好 → 幻觉、谄媚、永久依赖人类；RLVR 优化可验证奖励 → 解决数学题但加剧「锯齿智能」、难以嵌入软件。Jev 的 RLCD（Reinforcement Learning for Calibrated Decisions）用 proper scoring rule 训练分布本身，优化「认识论诚实的概率」。

架构的黑盒还原

Jev 拒绝开源权重，社区用 1 万次 API 探测还原了它的架构：

  • 直接读出替代解码循环：200 个选项和 2 个选项延迟相同，证明是 readout head 一次算出全部概率，没有逐 token 生成
  • 共享 state + 隔离 question 分支：秘密代码放进兄弟问题 → 概率 0.00；放进共享 state → 0.90–0.92；前缀 KV cache 共享，1500 个问题仍数百毫秒返回
  • 顺序敏感性警示：参考信息放在选项首位/中间时正确率 12/16、11/16，放最后 16/16，放 state 48/48——生产决策策略必须做排列测试

被低估的信号

  1. 输出免费 = 定价权转移：从「按 token 计费」转向「按价值计费」，整个推理成本经济学可能被重写
  2. KV cache 共享 + 并行分支 = 从对话到批处理：agent 的「多轮对话」范式可能被「一次声明式决策」取代
  3. 评测权力的转移：拒绝 JevBench 意味着「模型好不好」的定义权正从学术基准转向产品内 workflow eval
  4. 编程语言建在 Jev 之上：决策原语成为新的编程抽象，比单点 API 调用更深远

我的判断

Jev 的真正创新不是「不生成文本」，而是把校准的概率输出变成可依赖的软件契约：类型安全 + 置信度 + 极低成本，让 AI 第一次可以埋在软件依赖链深处而不炸。这与「智能能力路由」趋势完全同向。

但要警惕三点：架构不透明、速度/成本数据带有利己偏差、fresh-math 32% 说明它远非万能。理性姿势是把它当作「智能 if-statement 基础设施」来用，而不是当作 AGI 来膜拜。对开发者，现在是拿 early access 做路由/校验/评分实验的最佳窗口；对观察者，盯住 RLCD 是否公开、输出免费是否持续，比盯 MMLU 分数更有信息量。
